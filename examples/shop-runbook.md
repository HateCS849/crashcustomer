# Sample Shop 운영 메모

## 주문 API 장애 이력

주문 생성(POST /api/{variant}/orders)은 결제 대행사를 동기 호출합니다. 대행사 점검 시간에는 503이 간헐적으로 발생하고, 피크 시간에는 응답이 3초 이상 지연됩니다.

지연 중 고객이 주문 버튼을 여러 번 눌러 중복 결제가 발생한 문의가 있었습니다.

## 모바일 네트워크

지하철 구간 등에서 요청이 중간에 끊기는 경우가 있습니다. 이때 화면이 아무 반응 없이 멈췄다는 문의가 반복됩니다.

## 재고 조회

화면 진입 시 재고 API(GET /api/{variant}/stock)를 호출합니다. 재고 DB 잠금 때문에 이벤트 시간대 동시 접속이 몰리면 응답이 수 초까지 느려진 적이 있습니다.

## 배포

배포 직후 정적 파일(JS) 캐시가 갱신되지 않아 구버전 화면이 새 API 응답 형식을 해석하지 못한 사례가 있습니다. 로그인 세션은 재배포 시 만료됩니다.

## 기타

누적 주문 수 API(GET /api/orders/count)는 관리자 화면에서만 사용합니다.
